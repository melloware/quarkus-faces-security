Jakarta Faces on Quarkus

One app. Same pages. Two ways to secure it.

This demo runs the exact same PrimeFaces pages, users and roles behind a Faces login page (Quarkus form authentication) or behind OpenID Connect with Keycloak. You pick the mode with a Maven profile.

Pick a mode

Unsecured

mvn quarkus:dev

No authentication at all. Secure pages are blocked and redirected here, so nothing leaks by accident.

Form login

mvn -Pbasic

A PrimeFaces login page posting to j_security_check, users and roles embedded in application-basic.properties, logout clears the encrypted cookie.

OIDC (Keycloak)

mvn -Poidc

Keycloak started by Quarkus Dev Services (Docker), same users imported from a realm file, single logout through Keycloak.
